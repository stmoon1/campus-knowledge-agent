# 需求

用户是查询公司制度的员工。目标是拿到能在原文核对的答案，并知道资料不足或冲突时需要补什么。

| 验收场景 | 成功标准 |
| --- | --- |
| 明确答案 | 用已检索并实际读取的原文回答，附文档 ID、日期和引文 |
| 文档冲突 | 对差旅期限给出两份不同证据，标记待确认 |
| 资料外问题 | 不生成制度答案，说明资料缺口 |
| 改写后的相似问题 | 通过语义选词或词表找到同一制度 |
| 上下文追问 | 结合前文确定所指制度，只回答当前问点 |
| 工具失败 | 保留失败观察；缺少可读证据时返回未完成 |

范围限定于本地合成文档、CLI、一个 Agent 和两个只读工具。每次运行最多 8 次模型决策，可配置。
