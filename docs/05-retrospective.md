# 复盘

最难的是在模型自主选动作的同时保住证据边界。只要求模型附来源时，模型仍可能漏读相反条款。当前实现让模型选择何时检索、读原文或结束，运行器检查同主题的版本是否都读过，再从库中原样摘录，确保候选回答可回溯。

词表适合这个小型合成库。扩大到真实制度时，应加入语义召回与覆盖率评估，并按明确的生效期、适用范围与优先级做冲突判断。当前遇到同主题不同文本就保守标为待确认，可能把等义措辞判成冲突。

## 本机复跑观察

亲自复跑冲突样例时，我核对了 Trace 中的检索、两次原文读取和冲突报告。两份条款均出现在最终引用中，答案字段为空，系统请求确认制度适用范围或优先级。这条记录可以用来区分“发现冲突后需要确认”和“模型直接选择其中一个版本”。
